# TP Stables

## Requirements

1. Framework Base (TPZ-CORE, VORP, RSG)
2. TP Inputs: https://github.com/TitansProductions/tp_inputs
3. TP Notify: https://github.com/TitansProductions/tp_notify (download stable icons if you already have tp_notify)
4. TPZ Menu Base: https://github.com/TPZ-CORE/tpz_menu_base
5. TPZ SkillCheck: https://github.com/TPZ-CORE/tpz_skillcheck (for taming)
6. TP Containers: https://titans-productions.tebex.io/package/6559704

## Commands 

| Command                          | Ace Permission                     | Description                                                               | Console / TXAdmin Console Support |
|----------------------------------|------------------------------------|---------------------------------------------------------------------------|-----------------------------------|
| addhorse [source] [model] [sex]  | tp_stables.addhorse           | Execute this command to add (give) a horse on the selected player source. | Yes |
| addwagon [source] [model]        | tp_stables.addwagon           | Execute this command to add (give) a wagon on the selected player source. | Yes |

- The ace permission: `tp_stables.all` Gives permissions to all commands ONLY for this script.
