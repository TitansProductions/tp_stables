# What has been updated?

## Changelog - (Added, Fixed, Removed):

- Added new horse taming systems when a player goes to the stable for selling it or stable it with camera preview and better controls. Also, selling percentage receive has been added, sell or stable prompts can now be enabled or disabled (for example you might want to allow only selling or only stable a horse).
- Added horse eating prompt when leading the horse to feed the animal on feeding objects like feedtrough.
- Added horse drinking possibility on objects like watertrough.
- Added horse weapon holder for allowing the players to place their weapon on the horse.
- Added horse aging scale to scale the horses based on their age (their height adjustment).
- Added horse pregnancy scaling system based on the horse pregnancy current - total duration.
- Fixed an issue on leading actions (drinking, resting, wallow), they were never actually displayed to do them - this occured because the feature was made in another version and when i uploaded, the new features haven't been added.
 -Fixed a bug on leading actions, when drinking, resting, wallow, if you cancelled the horse task, the cooldown would still run when it really should just reset.
- Fixed an error that could occur on horse shoes for a miss-typed value when server was starting.
- Fixed an issue receiving synced warnings related to broken / missing entities (`0`) - caused by `NetworkGetNetworkIdFromEntity`.
- Removed the custom spawned horses for taming because that would confuse the players when trying to tame in-game horses, now the taming is through in-game spawned horses only and not custom spawned ones. Also, the horse is not getting deleted but running away instead.

- Remove the previous `Config.Taming` option from `config.lua` and add the new one:

```lua
Config.Taming = {

	-- Set to true to enable taming mechanisms and selling / ownership systems once a horse is tamed.
	Enabled = true,

    -- To disable the required jobs, set @RequiredJobs to false. 
    -- Example: Jobs = {"wapiti", "wapitishaman", "comanche", "valhorsetrainer", "horsetrainer", "anneshorsetrainer", 'blackhorsetrainer', 'strhorsetrainer', 'sdhorsetrainer', 'thieveshorsetrainer'},
    Jobs = false,
	
	-- When does the taming starts? after how many seconds to prepare the player?
	StartTamingCountdown = 6, -- time in seconds

	-- What should be the aged of the tamed horse in case the player wants for his ownership?
	OwnershipTamedHorseAge = { min = 20, max = 30 },

	-- Set to false if you dont want to allow players to be able to set the tamed horse as owned (get it to their ownership)
	AllowHorseOwnershipPrompt = true, -- 1.0.2

	-- Set to false if you don't want to allow players to be able to sell the tamed horse.
	AllowHorseSellPrompt = true,-- 1.0.2

	-- The money the player will receive is based on the horse model located on config/config_horses.lua file.
	-- Set the desired percentage that the player will collect when selling a tamed horse model.
	-- The model data value is "SELL CASH" from the config file.
	-- That means, if a_c_horse_turkoman_black SELL_CASH is 175, the 100% by default will give the player 175.
	SellHorseReceivePercent = 30, -- % ( version 1.0.2 )
}
```
