# What has been updated?

## Changelog - (Added, Fixed, Removed):

1. Fixed an issue on leading actions (drinking, resting, wallow), they were never actually displayed to do them - this occured because the feature was made in another version and when i uploaded, the new features haven't been added.
2. Fixed a bug on leading actions, when drinking, resting, wallow, if you cancelled the horse task, the cooldown would still run when it really should just reset.
3. Fixed an error that could occur on horse shoes for a miss-typed value when server was starting.
4. Added horse aging scale to scale the horses based on their age (their height adjustment).
5. Added horse pregnancy scaling system based on the horse pregnancy current - total duration.
