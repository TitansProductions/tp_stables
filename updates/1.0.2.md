# What has been updated?

## Changelog - (Added, Fixed, Removed):

- Added horse eating prompt when leading the horse to feed the animal on feeding objects like feedtrough.
- Added horse drinking possibility on objects like watertrough.
- Added horse weapon holder for allowing the players to place their weapon on the horse.
- Added horse aging scale to scale the horses based on their age (their height adjustment).
- Added horse pregnancy scaling system based on the horse pregnancy current - total duration.
- Fixed an issue on leading actions (drinking, resting, wallow), they were never actually displayed to do them - this occured because the feature was made in another version and when i uploaded, the new features haven't been added.
 -Fixed a bug on leading actions, when drinking, resting, wallow, if you cancelled the horse task, the cooldown would still run when it really should just reset.
- Fixed an error that could occur on horse shoes for a miss-typed value when server was starting.
- Fixed an issue receiving synced warnings related to broken / missing entities (`0`) - caused by `NetworkGetNetworkIdFromEntity`.
- Removed the custom spawned horses for taming because that would confuse the players when trying to tame in-game horses, now the taming is through in-game spawned horses only and not custom spawned ones.

## Modified Files:

- client/horses.lua
