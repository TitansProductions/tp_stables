# What has been updated?

## Changelog - (Added, Fixed, Removed):

1. Added better `whistling` and `fleeing` systems for the horse.
2. Added when spawning the horse new natives for `ClearPedEnvDirt`, `ClearPedDamageDecalByZone` and `ClearPedBloodDamage`
3. Added sex selection when purchasing horses.
4. Improved menu responsiveness when switching between sections while the camera and fade effects are loading.

## Modified Files:

- client/horses.lua
- client/functions.lua
- client/menu.lua
- fxmanifest.lua
