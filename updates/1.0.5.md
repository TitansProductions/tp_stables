# What has been updated?

## Changelog - (Added, Fixed, Removed):

1. Added better `whistling` and `fleeing` systems for the horse.
2. Added when spawning the horse new natives for `ClearPedEnvDirt`, `ClearPedDamageDecalByZone` and `ClearPedBloodDamage`
3. Added a new `NUI` which allows you when purchasing a horse to select sex (male / female) and also the payment method without using tp_inputs.
4. Added a new `NUI` which allows you when purchasing a wagon to select the payment method without using tp_inputs.
5. Added a new `NUI` for the horse shoes selection dialog.
6. Added sidesaddle command for the horses to side saddle on horse.
7. Added small pelt stow system for horses to carry small pelts properly by the system - in-game mechanisms are not functional, we had to make our own.
8. Fixed account balance formatting by displaying Cash with two decimal places.
9. Improved menu responsiveness when switching between sections while the camera and fade effects are loading.
