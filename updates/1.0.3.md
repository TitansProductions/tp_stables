# What has been updated?

## Changelog - (Added, Fixed, Removed):

- Added thirst and hunger metabolism drain system for the horses.
- Added new API lua file which allows you to get spawned horse entity and spawned horse statistics (hunger, thirst, stamina, health, etc).
- Fixed an issue on horse taming that once taming started, the remaining time would freeze on `1` second, that would occur because when calming the horse before the skillcheck starts, it would bug.
- Fixed an error on wagons that would occur when opening the wardrobes.
- Fixed on horse led actions the given statistics which are now given once the duration is finished than allowing players to abuse cancel animation, they would not let their horses to do those actions and they would abuse the given statistics.
- Fixed horse scaling on height adjustments, the scaling was not functional because the `SetPedScale` had to be set as last.
- Fixed horse spawning, because of height adjustments and components, the spawned horse on 1st / 2nd second(s), the changes would be visible, now the horse won't be spawned as buggy.

- Add the new metabolism system for horses on `config.lua` file.

```lua

-----------------------------------------------------------
--[[ Horse Breeding (1.0.3) ]]--
-----------------------------------------------------------

-- THIRST AND HUNGER MAX VALUES = 1000 
Config.Metabolism = {
    
	Enabled = true,

    HungerStripeValue    = 0, -- When hunger equals to the selected value, you start losing health.
    ThirstStripeValue    = 0, -- When thirst equals to the selected value, you start losing health.
    HealthDamageValue    = 5,

    -- This is the time rate which takes to execute the hunger and thirst drain 
	-- Every how long should the timer remove the hunger and thirst values.
    TimeRateRepeat       = 3, -- Time in seconds.

	HungerDrainIdle      = 0.25,  -- Hunger drop rate while standing.
	HungerDrainWalking   = 0.60,  -- Hunger drop rate while walking.
	HungerDrainRunning   = 1.30,  -- Hunger drop rate while running.
	
	ThirstDrainIdle      = 0.40,  -- Thirst drop rate while standing.
	ThirstDrainWalking   = 1.00,  -- Thirst drop rate while walking.
	ThirstDrainRunning   = 2.00,  -- Thirst drop rate while running.

	-- Set to false if you don't want to show the thirst and hunger values on prompt name (when focusing on horse with right-click hold)
	DisplayHungerAndThirstOnHorsePromptName = true,

	PromptThirst = 'Thirst',
	PromptHunger = 'Hunger',

	-- Set to false if you don't use tpz_hud.
	tpz_hud = false,
}

```
